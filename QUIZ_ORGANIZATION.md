## Level Structure

Most assessment categories follow a 2-level structure:

```
Category
├── Level 1 (Foundational)
│   ├── Simpler stimuli
│   ├── More support/scaffolding
│   └── Introduction to concept
│
└── Level 2 (Advanced)
    ├── Complex stimuli
    ├── Less support
    └── Mastery assessment
```

**Categories with Levels:**
- Visual Discrimination (Shapes, Size)
- Visual Closure (Animals)
- Visual Form Constancy (2 levels with subtypes)
- Visual Spatial
- Visual Neglect
- Figure Ground (via Memory Image Quiz levels)

**Single-Level Categories:**
- Visual Memory
- Visual Sequential Memory
- Motion Perception
- Pursuit & Fixation
- Observation
- Biological Motion (placeholder)

## File Naming Convention

### Pattern: [Category][Type][Level][Variant]

**Examples:**
- `VDT1.html` = Visual Discrimination + Type + Level 1
- `VFC12.html` = Visual Form Constancy + Level 1 + Variant 2 (letters)
- `VSpac2.html` = Visual Spatial + Level 2

**Prefixes:**
- VD = Visual Discrimination
- VC = Visual Closure
- VFC = Visual Form Constancy
- VM = Visual Memory
- VN = Visual Neglect
- VSpac = Visual Spatial
- VSM = Visual Sequential Memory
- FG = Figure Ground
- Vmotion = Visual Motion

**Types (for VD):**
- T = Shapes
- TC = Colors
- TS = Size
- TSE = Social/Emotions

**Levels:**
- 1 = Level 1 (Foundational)
- 2 = Level 2 (Advanced)

**Variants (for VFC):**
- 1 = Numbers
- 2 = Letters
- 3 = Size
